# Personalized Learning AI

An AI-powered personalized learning assistant that analyzes a learner's goals, experience, skills, interests, learning preferences, previous learning, and available time to generate an adaptive learning roadmap.

The platform combines AI-generated learning material, practice tasks, assessments, curated learning resources, progress tracking, and an AI learning assistant into one personalized learning experience.

---

## Problem Statement

Online learning platforms provide thousands of courses and resources, but learners often struggle to determine:

- What they should learn first
- What prerequisites they need
- Which skills they are missing
- Which resources are best suited to their goals
- How to measure their progress
- What they should learn next after completing a module

A one-size-fits-all learning path is often ineffective because learners have different backgrounds, goals, skill levels, learning preferences, and amounts of available study time.

Personalized Learning AI addresses this by generating an individualized learning path based on each learner's profile and continuously adapting recommendations using progress and feedback.

---

## Key Features

### Personalized Onboarding

Learners provide:

- Learning goal
- Experience level
- Existing skills
- Interests
- Completed courses / previous learning
- Learning preference
- Weekly learning commitment

This information forms the learner profile used by the AI.

### AI Skill-Gap Analysis

The AI analyzes:

```text
Goal
+
Experience
+
Existing Skills
+
Previous Learning
+
Interests
+
Learning Preference
+
Weekly Hours
```
